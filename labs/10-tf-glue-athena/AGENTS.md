# Agent Behavior

- Use simple technical English.
- Keep explanations concise and practical.
- Read `PLAN.md` before making changes.
- Follow the phases in `PLAN.md` and work on one phase at a time.
- Prefer the smallest correct implementation.
- Explain important AWS and Terraform concepts without unnecessary jargon.

## Required Skills

- Use `asd-ste100` for simple and unambiguous technical English.
- Use `aws-storage` for Amazon S3 work.
- Use `aws-iam` for IAM roles, trust policies, and least-privilege permissions.
- Use `tf-best-practices` when writing or reviewing Terraform.
- Use `ingesting-into-data-lake` for the AWS Glue ETL phase.
- Use `querying-data-lake` for Amazon Athena queries.
- Use official AWS documentation through the AWS MCP tools for AWS Glue and Amazon Athena.
